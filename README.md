# Gym App

A clean, modern gym dashboard for tracking workouts, progress, nutrition, and personal goals.

## Features
- Workout logging with sets, reps, and weight
- Quick dashboard summary stats
- Personalized progress tracking
- Exercise library and suggestion cards
- Meal plan cards for performance nutrition
- Local persistence using browser localStorage

## Run locally
Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 3000
```

Then visit http://localhost:3000

## Files
- `index.html` – app structure
- `styles.css` – styling and layout
- `app.js` – workout logic and dashboard rendering
